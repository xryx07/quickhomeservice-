# Quickhome — Home Services, Considered

A platform providing vetted home service professionals, fixed upfront pricing, and a smooth booking experience across 142 Indian cities.

## Features

- **On-Demand Home Services**: Book electricians, plumbers, appliance repair, deep cleaning, and more.
- **Fixed & Transparent Pricing**: Upfront quotes with no hidden costs.
- **Vetted Professionals**: Certified background-checked service partners.
- **Interactive Assistant**: Built-in chat assistant for service recommendations and FAQs.
- **Responsive Web UI**: Built for mobile, tablet, and desktop experiences.

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or bun

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS, Radix UI, Lucide Icons, Framer Motion
- **Database / Backend**: Supabase
- **Language**: TypeScript
